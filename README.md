# Robyn MMM – R Standalone Demo

This repository contains a **standalone, reproducible example** of running
**Meta’s Robyn Marketing Mix Model (MMM)** in **R on Windows**, using
**Anaconda Python + nevergrad** via `reticulate`.

The demo project demonstrates:
- End-to-end Robyn setup
- Synthetic data with known media effects
- Model execution and output interpretation


## Project Structure

.
├── robyn_standalone.R # End-to-end Robyn script
├── README.md # This file
└── .gitignore # (recommended)



---

## Requirements

- R ≥ 4.5
- RStudio (recommended)
- Anaconda / Conda (Python ≥ 3.10)
- R packages:
  - `Robyn`
  - `reticulate`

Robyn uses **Python's `nevergrad`** for optimization.

---

## How to Run

1. Open the project in **RStudio**
2. Run `robyn_standalone.R`
   - The script:
     - configures Python via `reticulate`
     - installs / verifies `nevergrad`
     - creates synthetic weekly data
     - runs Robyn end-to-end
3. Review outputs generated by Robyn

## Notes on the Data

Revenue is **synthetically generated** to depend on media spend:
